**🍽️ Serverless Food Data Engineering Pipeline (GCP Free Tier, No Docker)**

This project demonstrates a fully serverless data engineering pipeline designed for Google Cloud Platform (GCP) using Cloud Functions, Cloud Storage, BigQuery, and a lightweight static dashboard. The goal is to build an automated ETL workflow that ingests recipe data from a public API, transforms it into a structured dataset, and visualizes insights without requiring Docker, VMs, or paid cloud services.

The pipeline begins with an HTTP-triggered Cloud Function that fetches recipe data from TheMealDB API and stores raw JSON snapshots in a Cloud Storage bucket. A second event-driven Cloud Function automatically processes each new raw file, extracting key fields such as recipe name, cuisine, ingredients, and timestamps. The cleaned data is saved back to Cloud Storage as processed JSON, and optional logic is included to load curated rows into a partitioned BigQuery table for analytics. A simple web dashboard, built using HTML and Chart.js, fetches the processed JSON directly from Cloud Storage and renders interactive visualizations such as cuisine distribution counts.

Although deployment to GCP is currently pending due to billing verification issues, the full production-ready codebase is included in this repository and fully deployable once the GCP account becomes active. The project follows industry-standard data engineering concepts including serverless ETL, event-driven orchestration, schema design, analytics-ready output generation, and cloud-native hosting.

This project is intentionally built to run within GCP’s Always Free Tier, requiring no Docker setup, no VM allocation, and minimal configuration. Once deployed, it provides a clean demonstration of an end-to-end data pipeline suitable for portfolio use, interviews, and academic or organizational submissions.
